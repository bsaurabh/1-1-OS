# Personas — 1:1OS

## Persona 1: The Design Manager

**Name**: Saurabh (representative)
**Role**: Senior Design Manager / Design Lead
**Organization type**: Fast-paced product company (fintech, e-commerce, SaaS)

### Demographics & Context
- Manages 5–10 designers
- Handles revenue-linked design projects (e.g., trading flows, onboarding, conversion)
- Splits time between IC design work and people management
- Runs weekly or bi-weekly 1:1s with each direct report
- Works across multiple workstreams simultaneously (multiple product contexts, multiple teams)

### Goals
- Grow each designer from functional to excellent
- Identify skill stagnation and growth plateaus early
- Be prepared and sharp in every 1:1 — no wasted sessions
- Track commitments so nothing falls through the cracks
- Have coaching conversations, not just status update conversations
- Measure impact of 1:1s on designer performance over time

### Frustrations
- Context-switching between reportees causes important signals to be forgotten
- Notes in Google Sheets are passive — they don't surface insights or remind him proactively
- Follow-ups from last week's 1:1 get lost between sessions
- Coaching is reactive ("something went wrong") rather than strategic ("I saw this coming")
- Hard to see growth patterns when each 1:1 is treated as an isolated event
- No tool understands the nuance of each individual designer's arc

### Behaviors
- Takes light notes during meetings but rarely has time to process them properly
- Relies heavily on memory for context about each person
- Uses calendar to schedule 1:1s but nothing to prepare for them
- Reviews Slack history before important conversations
- Uses intuition-based coaching, not a structured framework

### Mental Model
- Thinks in terms of individuals, not systems
- Values craft, ownership, and visual excellence as outcomes
- Wants to be challenged to have uncomfortable conversations he might avoid
- Trusts data-backed nudges more than generic advice

### Technology Comfort
- Comfortable with web apps; uses Figma, Notion, Slack daily
- Not a developer; expects UI to be intuitive without documentation
- Open to AI tools if they provide clear, contextual value — not generic outputs

### Key Quote
> "I don't need another place to dump notes. I need something that makes me a better manager in the room."

*No secondary persona defined. Design Manager is the sole user of the application.*
